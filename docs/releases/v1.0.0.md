# PAMS v1.0.0

Release readiness date: **2026-07-23**

PAMS v1.0.0 is the first usable production-style release of the local-first
Personal Asset Management System.

## Included

- Transaction ledger and deterministic holding projection
- Official TWSE and TPEx latest and historical closing-price ingestion
- Canonical Decimal-based portfolio valuation
- Snapshot-based basic portfolio analytics
- Operational, valuation, analytics, and reporting CLI workflows
- Streamlit Dashboard
- Markdown and standalone semantic HTML reports
- SQLite persistence and deterministic demo data
- Automated tests, CI, governance, and security guidance

## First run

```bash
python -m pip install -e .
python -m pams demo-data
python -m pams portfolio valuate --database data/pams_demo.db
python -m pams analytics portfolio --database data/pams_demo.db
python -m streamlit run app.py -- --database data/pams_demo.db
```

## Integrity guarantees

- Financial calculations use `Decimal`.
- Missing prices are not replaced with stale values.
- Official market dates are verified before persistence.
- Quote and snapshot persistence is atomic.
- Presentation consumes Application Layer DTOs and does not calculate financial
  results.

## Known limitations

- Taiwan-listed equities only
- One currency context; no FX conversion
- No allocation or benchmark analytics
- No TWR, MWR, IRR, or XIRR
- No broker importers
- No scheduling or notifications
- Local SQLite only; backup operations remain the user's responsibility
