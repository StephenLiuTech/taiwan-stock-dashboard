# PAMS v0.8.0

Release date: **2026-07-22**

PAMS v0.8.0 is the first production-ready portfolio valuation and reporting
release. It establishes one Decimal-safe valuation source for operational CLI,
Streamlit, persisted portfolio workflows, and reusable daily reports.

## Highlights

### Portfolio Valuation Engine

- Pure `ValuationEngine` with no repository or framework dependencies
- Immutable holding-level and aggregate valuation DTOs
- Cost basis, market value, unrealized profit or loss, and returns calculated
  with `Decimal`
- Application-owned holding and latest-quote loading
- Typed `MissingQuoteError` for incomplete portfolios
- Human and lossless JSON CLI output

```bash
python -m pams portfolio valuate
python -m pams portfolio valuate --json
```

### Dashboard 2.0

- Streamlit consumes one cached `PortfolioValuation`
- Portfolio Summary
- Largest Positions
- Allocation by holding
- Top Winners and Top Losers
- Sortable complete holdings table
- No repository, SQL, provider, or valuation-formula access in dashboard code

```bash
python -m streamlit run app.py
```

### Daily Report Engine

- Presentation-neutral and deterministic `DailyReportBuilder`
- Independent Markdown and semantic HTML renderers
- No JavaScript, external CSS, CLI, dashboard, repository, or SQL dependencies
- Standard-output and UTF-8 file generation

```bash
python -m pams report generate
python -m pams report generate --output report.md
python -m pams report generate --html --output report.html
```

## Existing operational capabilities

v0.8.0 retains:

- official TWSE and TPEx latest and historical providers
- strict official source-date verification
- safe no-update handling while latest market publications are staggered
- atomic quote and aggregate/position snapshot persistence
- moving weighted-average transaction ledger
- explicit dry-run and atomic holding rebuild
- operational `status` and `verify` commands
- isolated deterministic demo data

## Installation

Python 3.11 or 3.12 is required.

```bash
python -m venv .venv
python -m pip install -e ".[dev]"
python -m pams --help
```

To evaluate the user experience without live data:

```bash
python -m pams demo-data
python -m streamlit run app.py -- --database data/pams_demo.db
```

Demo data is synthetic and must not be used for investment decisions.

## Compatibility and data safety

- Existing SQLite schema and snapshots remain compatible.
- No schema migration is introduced by v0.8.0.
- Historical aggregate and holding-level snapshots remain immutable.
- Existing reporting functions remain import-compatible through
  `pams.reporting` re-exports.
- Manual market updates still require exact historical source-date matches.
- Automatic updates still wait until latest-only TWSE and TPEx publications
  expose the same official date.

Before using a production database, keep a separate file-level backup. PAMS is
local portfolio software and does not provide investment advice.

## Known limitations

v0.8.0 intentionally does not include:

- scheduling or background execution
- email, Telegram, or other report delivery
- broker imports
- corporate-action automation
- authentication or multi-user access
- cloud persistence

## Upgrade notes

No database migration is required. Reinstall the editable project to refresh
package metadata and console entry points:

```bash
python -m pip install -e ".[dev]"
```

Then confirm local readiness:

```bash
python -m pams status
python -m pams verify
```
